chadtab

The hygiene routine for hunky hosts.
Cron that never skips leg day.

A successor to cron. One plain table runs your scheduled work on GNU/Linux and on Windows alike, makes up the runs it missed, keeps a record of every one, and shows you how it has been going.

# chadtab: today's routine
PATH=/usr/local/bin:/usr/bin:/bin
*  backup   cron:17 3 * * *  catchup
|  --->     !sh backup.sh
|  % <--- @ status bytes ..note
|  -->>     log/backup.jsonl
|  ==>      c4:reg/hosts avalon backup $status
*  pulse    every:15m+4m
*  start    boot

The routine

  • Never skips leg day.

    A job marked catchup runs once for a time it missed while the machine slept or was switched off. Plain cron just lets that one go.

  • Logs every rep.

    Every run is one line of JSON: what ran, when, how long, what it said and how it ended. Each job's last result and recent history are kept where any tool can read them.

  • Same routine at any gym.

    The same table runs on GNU/Linux and on Windows, without the Task Scheduler: chadtab startup starts it when you sign in. Python's standard library is all it needs.

  • Warms up before the heavy lifts.

    Run-levels: a job can wait until its host is at the level it needs.

  • Always lifts with a spotter.

    A fact a job learns can be written into a C4 registry by two writers that read each other back. Nobody sees it until both agree; if they disagree, the old value goes back on both sides and the journal says so.

  • Checks his form in the mirror. Twice.

    Every clock is read by two programs that share no code, one in Python and one in Emacs Lisp, against rows counted by hand on a calendar. Eight planted faults are each caught by the tests, and three more by the check that holds the program to its grammar. The tests run here, hourly, by chadtab itself: see the latest set.

  • Shows you the numbers.

    chadtab top in a terminal, M-x chadtab-status in Emacs.

What it keeps from cron

A table you can read, keep under version control, and copy between machines. Five-field cron times, with month and day names. Chad respects his elders.
